# 🏢 Hermes Virtual Office

Real-time visual office dashboard for monitoring Hermes AI Agents.

## 🚀 Features
- **Real-Time Visual Dashboard**: Monitor agent states (`IDLE`, `THINKING`, `EXECUTING`, `COMPLETED`).
- **Zero-Dependency Backend**: Built using pure Node.js standard libraries (`http`, `fs`, `events`).
- **Live Stream via SSE**: Uses Server-Sent Events (SSE) for instant status updates.
- **Task Dispatcher**: Interactive UI to send tasks directly to specific agents.

## 📦 Quick Start

```bash
# Clone repository
git clone https://github.com/bembenk18/Hermes-Virtual-Office.git
cd Hermes-Virtual-Office

# Run server
node server.js
```

Open browser at `http://localhost:3000`.
